### Fixed
- **2026-11-28** — Sped up Community/Helm Add-on details inspection (`AddOnDetailsDialog.tsx`, `backend/main.py`) by caching cluster endpoint/CA (`90s`) and add-on details (`30s` backend + `25s` SWR client cache), parallelizing `helm status`, `helm get values -o yaml`, and `kubectl get pods,svc,ingress,events`, stripping `USER-SUPPLIED VALUES:` headers, adding `<LinearProgress />` loading states, and filtering Services, Pods, Ingresses, and Events exclusively to resources owned by the selected add-on (`_k8s_item_matches_release`, `_k8s_event_matches_release`, `matchesCommunityAddonPod`).
- **2026-11-28** — Fixed community add-on Helm uninstall UX in `AddOnDetailsDialog.tsx`, `ClusterDetails.tsx`, and `backend/main.py`: close `ConfirmDeleteDialog` immediately on confirmation and keep the add-on details modal open on `Install Logs & Events` to display streaming/final `helm uninstall` logs (`_uninstall_community_addon_sync`, `_latest_addon_history_entry`), separate `uninstallingAddonIds` from `installingAddonIds` so both the modal and table show `Uninstalling...` instead of `Installing...`, and reset confirmation/live states across add-on switches (`frontend/src/components/Clusters/AddOnDetailsDialog.tsx`, `frontend/src/pages/ClusterDetails.tsx`, `backend/main.py`).
- **2026-11-27** — Fixed `cluster-proportional-autoscaler` Helm install failure (`options.target must be one of deployment, replicationcontroller, or replicaset`) by defaulting `options.target=deployment/coredns`, added per-release `threading.Lock` + `_clear_stuck_helm_release` auto-recovery for concurrent `pending-install`/`pending-upgrade` Helm operations, cleared `inflightRequests` alongside `cacheStore` in `swrCache.ts`, and switched `ClusterDetails` add-on install buttons from single `installingAddonId` to per-add-on `installingAddonIds` map (`backend/main.py`, `frontend/src/pages/ClusterDetails.tsx`, `frontend/src/utils/swrCache.ts`).
- **2026-11-27** — Fixed clusters created from Tesserak (or synced manually) remaining stuck on `Needs Sync` (`node_group_count_mismatch`) by passing live `nodeGroups` in `_list_clusters_sync`, unwrapping `current_state["state"]` and syncing `nodeGroups` in `sync_cluster_state` + `state_management.py`, and syncing local state after `_finalize_cluster_addons` (`backend/main.py`, `backend/state_management.py`).
- **2026-11-27** — Fixed active AWS-only clusters (`missing_local`) counting toward `Missing / Deleted` on the `EKS State Health` donut chart (`frontend/src/pages/Clusters.tsx`).
- **2026-11-27** — Preserved Auth0/Google SSO `picture` URLs when PostgreSQL profile records return an empty `avatarUrl`, backfilled DB avatars cleanly, added `tesserak-profile-updated` reactivity in `AuthContext.tsx` and `App.tsx`, and added `referrerPolicy="no-referrer"` on `<Avatar>` images (`frontend/src/auth/AuthContext.tsx`, `frontend/src/App.tsx`, `frontend/src/pages/Profile.tsx`).

### Added
- **2026-11-27** — Strict `account_id`-scoped connector lookup (`ConnectionManager.get_connection_for_account`, `_resolve_account_connection`) and optional read-only platform catalog fallback (`get_platform_catalog_connection`, `get_catalog_connection`, `TESSERAK_CATALOG_AWS_*`) across AWS/EKS endpoints (`backend/connections.py`, `backend/main.py`, `backend/.env.example`, `backend/test_fixes.py`).
- **2026-11-27** — Persistent feature catalog documenting all backend endpoints, frontend routes, database models, and configuration (`docs/FEATURES.md`).
- **2026-11-26** — Hybrid memory + PostgreSQL EC2 catalog persistence table (`AwsCatalogCacheRecord` / `aws_catalog_cache`) and live AWS EC2 instance-type filtering by EKS AMI type with vCPU/memory/architecture/GPU metadata (`backend/db.py`, `backend/main.py`, `frontend/src/components/CreateCluster/InstanceTypeSelect.tsx`, `frontend/src/components/CreateCluster/NumericCountField.tsx`).
- **2026-11-26** — Live Kubernetes node and paginated pod inspector modal (`10` pods per page), reusable destructive action confirmation dialog, and automatic Kubernetes workload cleanup on pipeline deletion (`frontend/src/components/Clusters/NodeDetailsDialog.tsx`, `frontend/src/components/ConfirmDeleteDialog.tsx`, `backend/pipelines_service.py` `cleanup_pipeline_deployments_sync`, `backend/tesserak_router.py`).
